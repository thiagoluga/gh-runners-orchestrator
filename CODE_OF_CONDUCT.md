# Code of conduct

Be decent to people. Assume the person you are replying to is trying to make the project
better, and answer the argument rather than the person.

Not acceptable here: harassment, insults, personal or political attacks, publishing
someone else's private information, and sexualized language or imagery.

The maintainer may edit or remove comments, issues and pull requests that break this, and
may block someone who keeps doing it.

To report a problem privately, use the contact on the maintainer's GitHub profile
([@thiagoluga](https://github.com/thiagoluga)). Reports are kept confidential.
